本仓库是 InterWise AI 模拟面试系统的个人学习与功能实践公开快照。仓库展示的功能不自动等同于单人原创；个人实际负责的功能应结合源文件、测试和真实提交记录逐项说明。

## 提交历史

公开仓库从一个基线快照开始，当前 Git 历史如实保留首次发布记录。该历史不能证明代码此前的逐步开发过程，本说明也不将其描述成完整开发日志。后续修改以新的真实提交记录追加，不追补或伪造旧提交。

## 已确认的来源边界

- 内置公共题库的来源已在 README 末尾注明为 mianshiya.com；再分发前应复核原始内容许可和使用要求。
- Java、Vue、数据库、中间件、模型 SDK 等第三方依赖以 `backend/pom.xml`、`frontend/package.json`、各服务依赖文件和对应许可证为准。
